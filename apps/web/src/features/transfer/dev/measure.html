Upload measurement (SPEC R7.2: while a 10 GB file uploads, browser memory stays stable and other people's typing and terminals show no noticeable delay)

Uploads from a synthetic file source (each chunk is computed when it is read), so no 10 GB file appears on the local disk. The upload goes through the real transfer Worker, Noise encryption, the relay's TransferDO and the daemon. By default it ends with file.upload.abort, so no file stays on the host's computer. Join the workspace in the same browser the normal way first (the device key and the host key are then in IndexedDB). The host's reserved disk space rule still applies: check that the host's settings allow this size before measuring.

Automation: open with ?ws=<id>&gib=10&autostart=1; when it has finished, document.body.dataset.measureState is done and the result is in window.__smurgMeasure. The page only sees the JS heap of its own main thread; measure the memory of the whole browser from outside (for example sample every process of this browser with ps -o rss= once a second).
