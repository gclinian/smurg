等你看完成2 項通過 · 1 項未驗證Claude 撰寫，14:02smurg/checkout-redesign/receipt-email

做了什麼

  • 付款成功後寄出收據信，內容有訂單明細、總金額和訂單編號。
  • 信件有 HTML 版和純文字版，支援英文與繁體中文。

為什麼這樣做

  • 信件由佇列寄出，而不是在付款請求裡寄：郵件伺服器變慢時，買家不該跟著等。
  • 範本重用了訂單摘要元件，頁面和信件的內容不會不一致。

怎麼驗證的

  • pnpm test email: 9 個測試通過
  • 用 3 筆範例訂單產生信件，並和儲存的快照比對
  • 未驗證：實際寄送。這個工作區沒有郵件伺服器的設定。

要注意什麼

  • 佇列停擺時付款仍會成功，收據會等佇列恢復後才寄出。
  • 退款目前不會寄信：spec 裡沒有這一項。
