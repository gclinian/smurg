smurg v0.5.0: interface mock

Static pages (HTML + CSS + a little vanilla JS) on the app's real design tokens. Open any page; the left column, the columns, the dividers, the votes of a question and the answers of a permission request are clickable. The theme button in the top bar switches dark and light.

1. Main screen

  • 01-main.html: three columns: a conversation, the plan, a result report
  • 01-main.zh-TW.html: the same in Traditional Chinese
  • 01-main-empty.html: nothing open on the right
  • 01-main-first-run.html: a workspace without topics

2. A conversation column

  • 02-conversation-host.html: Host: running with streaming text, a permission request, a question
  • 02-conversation-editor.html: the same as an Editor (Amy)
  • 02-conversation-viewer.html: the same as a Viewer (Leo)
  • 02-states.html: every state of the cards, the composer and the header (a sheet)

3. A topic from start to finish

  • 03-topic-1-new.html: New topic
  • 03-topic-2-discussion.html: the shared discussion: the agent asks, everyone votes
  • 03-topic-3-spec.html: the spec, and asking the agent to revise it
  • 03-topic-4-spec-edit.html: editing the spec together
  • 03-topic-5-start.html: the Start dialog: what happens when you press Start
  • 03-topic-5-plan.html: the plan: work items, suggested responsible people, reassigning
  • 03-topic-5-plan-everyone.html: the plan with "Everyone watches"
  • 03-topic-6-execution.html: execution: the plan and three sessions side by side
  • 03-topic-7-report.html: a result report
  • 03-topic-8-complete.html: the topic is complete

4. Inbox

  • 04-inbox.html: an item was clicked: what opened, and where

  • 04-inbox-viewer.html: the inbox of a Viewer

5. Code mode

  • 05-code-mode.html: the workbench behind the switch, opened from a session's changed file
