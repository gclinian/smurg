# 快速上手：第一個主題

從零開始到第一個主題（一個功能或一件工作），最短的一條路：你從自己的電腦分享專案資料夾，組員用瀏覽器加入，agent
做完一件工作，再由你看過、合併。英文版：[English](../QUICKSTART.md)。

- **你（主人）**：需要 macOS 或 Linux，Claude Code 已經安裝並登入，還要有一個專案資料夾，而且是至少有一個提交的
  git 儲存庫（需要哪些版本：[主人指南](HOSTING.md#1-安裝) §1）。
- **每個人**：需要 Google 帳號，以及電腦上的 Chrome。組員不需要安裝任何東西。

## 把資料夾分享給團隊

1. **安裝 smurg**：

   ```sh
   curl -fsSL https://smurg.ai/install.sh | sh
   ```

   如果安裝程式說 `~/.local/bin` 不在 `PATH` 裡，把它印出的那一行加到它指名的檔案，再重新開啟終端機。之後
   `smurg --version` 會印出版本。

2. **分享資料夾**（換成你自己專案的路徑）：

   ```sh
   smurg host ~/projects/my-app
   ```

   如果它先請你登入：打開它印出的網址，用你的 Google 帳號登入，輸入代碼，按「下一步」，再按「允許」。
   接著它會印出兩個連結，並且繼續執行；這個終端機請開著：

   ```
   smurg 正在分享「my-app」

   你的連結（只給你自己用）：
     https://app.smurg.ai/join/ws_…#k=…&s=…

   給組員的連結（用私訊傳給他們，7 天內有效）：
     https://app.smurg.ai/join/ws_…#k=…&s=…

   按 Ctrl-C 停止分享。
   ```

3. **用 Chrome 打開「你的連結」**：如果畫面要你登入，按「使用 Google 登入」，再按「加入」。最上面一排會顯示
   「已連線」，頁面上寫著「從一個主題開始」。

> **把連結傳給組員之前**：agent 就是 Claude Code，以你的身分在你的電腦上執行，沒有沙盒，用的是你的 Claude 帳號，
> 替組員工作時也一樣。個人的 Claude 訂閱（Pro 或 Max）只供你自己使用：多人使用請改用 API 金鑰，或 Team、Enterprise
> 方案。只把「可使用 agent」給你完全信任的人。請先讀[分享前必讀](HOSTING.md#4-分享前必讀)。

4. **把「給組員的連結」傳給組員**：請用私訊傳，因為 `#` 後面那一段是密鑰。用這個連結加入的組員，角色是「可編輯」：
   看得到也可以編輯資料夾裡的檔案、對 agent 的選擇題投票，也和你一起檢視結果。想先自己一個人試試？直接從第 6 步繼續。
5. **組員用 Chrome 打開連結**：按「使用 Google 登入」，再按「加入」。不需要安裝任何東西，也不需要 Claude 帳號。
   他的畫面最上面一排也會顯示「已連線」。

## 第一個主題

6. **開一個主題**：按「新增主題」，填上名稱，寫下你想做什麼，再按「開始討論」。從這裡開始，按鈕都由你來按；
   「可編輯」的組員可以投票、留言、編輯 spec、對 agent 提出建議。
7. **一起決定**：agent 用卡片提出選擇題，卡片叫「Claude 的選擇題」。每個人各選一個選項；最後由你按「送出答案」
   （卡片裡有好幾題時，是「送出所有答案」）。
8. **等 agent 寫好 spec**：該決定的都定下來之後，agent 會寫出 `SPEC.md`（它待命時，你也可以按「現在就寫 spec」），
   並在討論裡告訴大家；按「開啟 spec」就能看。
9. **請 agent 寫計畫**：按「產生計畫」。agent 會寫出 `PLAN.md`：一份工作項目的清單。
10. **開始工作**：按「開始 3 個項目」（數字依你的計畫而定），讀過對話框的說明，再按「開始」。幾乎每個指令執行之前，agent
    都會先問你：卡片在你的收件夾（左上），叫「Claude 請求許可執行指令」。先讀指令，再按「允許一次」或「拒絕」。
11. **檢視**：工作項目做完時，它的結果報告會送到你的收件夾。讀完再按「我已看過」。
12. **合併**：這個項目的變更會出現在你的收件夾，寫著「已看過，可以合併」。打開它，按「合併…」，讀過 diff，再依序按
    「合併到主工作區」、「確認合併」。計畫會把這個項目顯示為「已看過 · 已合併」：它的變更已經在你的資料夾裡了。

## 接下來

- 遇到問題：[疑難排解](HOSTING.md#8-疑難排解)。做第一個主題時請多留意：這個流程是用照劇本回應的模型替身驗證的，
  沒有用真正的 Claude 帳號（[驗證過什麼](HOSTING.md#108-驗證過什麼還沒驗證什麼)）。
- 誰可以做什麼：組員指南的[角色](JOINING.md#2-角色可以做什麼)。
- agent 自己能做什麼、什麼要先問：[主人指南](HOSTING.md#52-agent-自己能做什麼什麼要先問) §5.2。
- 停止（Ctrl-C 或 `smurg stop`）與更新（`smurg update`）：主人指南的 [§7](HOSTING.md#7-狀態與停止) 和
  [§9](HOSTING.md#9-更新與移除)。
